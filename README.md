# Unique Cooling Center — Official Web Application

> **Professional Appliance Care & AC Servicing in Barrackpore & North 24 Parganas, West Bengal.**

An ultra-responsive, modern single-page web application for **Unique Cooling Center**, offering on-demand doorstep repair and maintenance for Air Conditioners, Washing Machines, Refrigerators, Kitchen Chimneys, Aquaguard & RO Water Purifiers, Geysers, and Microwaves.

---

## 🚀 Features

- **Direct Call Hotline & Instant Action**: Instant 1-tap phone connection to local repair dispatch supervisors.
- **Accurate Location & Directions**: Street-level interactive map targeting the exact business location in Barrackpore (`22.7728° N, 88.3734° E`) with 1-click Google Maps navigation.
- **Appliance Service Portfolio**: Clear diagnostic breakdowns and benefits for ACs, fridges, washing machines, chimneys, RO water purifiers, and water heaters.
- **Local Trust & Verified Reviews**: Real local customer ratings and service coverage across Barrackpore, Ichhapur, Palta, Babanpur, Shyamnagar, and North Barrackpur.
- **Modern Responsive Design**: Built with Tailwind CSS, Lucide icons, and Motion for fluid interactions across mobile, tablet, and desktop screens.

## 💻 Getting Started

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/) or [bun](https://bun.sh/)

### 2. Installation

Clone the repository and install dependencies:

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY

# Install dependencies
npm install
```

### 3. Development Mode

Run the local development server:

```bash
npm run dev
```

Visit `http://localhost:3000` (or `http://localhost:5173`) in your browser.

### 4. Build for Production

Compile the optimized static build:

```bash
npm run build
```

The output will be generated inside the `dist/` directory ready for deployment on Netlify, Vercel, GitHub Pages, or Cloud Run.

### 5. Preview Production Build

```bash
npm run preview
```

## 📦 How to Push to GitHub

If you haven't created a GitHub repository yet:

1. Go to [GitHub](https://github.com/new) and create a new empty repository (e.g. `unique-cooling-center`).
2. Run the following commands in your terminal:

```bash
# Initialize git if not already initialized
git init

# Add all files
git add .

# Create initial commit
git commit -m "feat: Initial commit for Unique Cooling Center web app"

# Set default branch to main
git branch -M main

# Link your GitHub remote repository
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

# Push the codebase to GitHub
git push -u origin main
```
